# 📱 Controle Financeiro App

Aplicativo móvel para controle de gastos pessoais desenvolvido com React Native e Expo.

## 🚀 Funcionalidades

- ✅ Login/Cadastro de usuários
- 📊 Estatísticas interativas com múltiplos gráficos
- 📸 Captura de notas fiscais com OCR
- 📝 Entrada manual de gastos
- 📈 Relatórios mensais e anuais
- 🤖 Assistente IA para análise financeira
- 🎯 Definição de metas mensais

## 🛠️ Tecnologias

- React Native
- Expo SDK
- React Navigation
- Expo Camera
- React Native SVG

## 📦 Instalação

```bash
# Clone o repositório
git clone <URL_DO_REPOSITORIO>

# Instale as dependências
npm install

# Inicie o projeto
npx expo start
```

## 📱 Como Usar
